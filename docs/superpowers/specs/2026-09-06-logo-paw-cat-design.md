# FourFeetCat Logo 设计（爪印猫）— 2026-09-06

## 结论

最终 logo 为「爪印猫」：一枚蓝色猫爪印，**掌垫即猫头**——无耳、无眼，只有粉鼻 + ω 笑嘴。
「四脚猫」三字全部画进一枚图形：四只脚趾 = 四脚，掌垫 = 猫；远看是爪印，近看那只猫在笑，谜面即谜底。

## 落定过程（视觉伴侣多轮比选）

1. 第一轮（常规解法：蓝面几何猫 / 白脸蓝耳 / 极简一笔猫 / 徽章方块猫）——全部否决，不够独特。
2. 第二轮（叙事方案：爪印猫 / 气泡猫 / 馒头猫 / 括号猫）——爪印猫胜出：想法是"一只爪印，四只脚趾，掌垫正是猫头"。
3. 优化：掌垫猫头去耳、去眼。
4. 再优化：脚趾更胖、间距收紧（紧凑）、嘴部表情方案比选（ω / 一弧 / 吐舌 / 腮红）。
5. 肉垫改为纯圆（心形/桃形否决——"不可爱"）。
6. 定稿：**变体 4 紧凑圆垫**——四趾下压、与圆掌垫几乎相切，ω 笑嘴。
