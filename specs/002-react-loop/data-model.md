# Phase 1 Data Model: ReAct 循环（第17节）

## 1. `tool_invocations` 表（本节唯一新增持久化结构）

来源：`docs/class/schema.sql` L47-58（课程参考建表脚本），逐字保真地摘取；SQLite 无原生 BOOLEAN/TIMESTAMP——布尔落 INTEGER(0/1)、时间戳落 TEXT（ISO-8601）。

| 列 | SQLite 类型 | PostgreSQL 类型 | 约束 | 说明 |
|---|---|---|---|---|
| `id` | INTEGER PRIMARY KEY AUTOINCREMENT | BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | 非空 | 主键 |
| `session_id` | VARCHAR(64) | VARCHAR(64) | 非空 | 关联会话（审计可按会话追溯） |
| `tool_name` | VARCHAR(64) | VARCHAR(64) | 非空 | 工具名 |
| `input_json` | TEXT | TEXT | 可空 | 模型给出的调用参数（JSON 字符串原样） |
| `result_json` | TEXT | TEXT | 可空 | 执行结果（工具返回内容）；失败为 NULL |
| `success` | INTEGER | BOOLEAN | 非空 | 成败（SQLite 0/1） |
| `error_message` | TEXT | TEXT | 可空 | 失败原因 |
| `duration_ms` | BIGINT | BIGINT | 非空 DEFAULT 0 | 执行耗时 |
| `created_at` | TEXT | TIMESTAMP | 非空 | 调用时间（ISO-8601） |

索引：`idx_tool_invocations_session ON tool_invocations(session_id)`。

**写入规则（宪法原则五）**：每次工具执行无论成败 MUST 写一条——成功 `success=1`、失败 `success=0` 且 `error_message` 非空；工具查不到（未注册）同属失败，照样落一条。

## 2. `Session`（内存态，第18节接持久化）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 会话标识；**拼接公式归第18节 SessionManager**，本节只持有 |
| `profileName` | String | 所属 Agent（`AgentService` 用它取 Profile） |
| `channel` | String | 接入渠道（本节只透传，取值来源归后续节） |
| `userId` | String | 用户标识（同上） |
| `messages` | `List<Message>`（Spring AI） | 按序累积：用户消息 →（每轮）助手响应 →（一次响应内多个工具调用）一条含多 `ToolResponse` 的工具结果消息 |

**不变量**：`messages` 按发生顺序追加，不重排、不删除（截断只发生在组装请求时，不改动会话本身）。

## 3. 前向契约（本节立、后续节接）

| 契约 | 本节的形态 | 谁接、怎么接 |
|---|---|---|
| `SessionManager` | 接口，仅 `save(Session)` | 第18节补 `getOrCreate`/`get` 与 JPA 实现；`session_id` 拼接公式只在实现内落地 |
| `ToolTable` | 接口：描述清单 + 执行 | 第20节由 `OryxTool` + `ToolRegistry` 合并替换 |
| `LlmCaller` | 接口：与 `ProviderService.chat` 同签名 | 装配处 `providerService::chat`；第16节类零改动 |
| 长期记忆 | `PromptBuilder` 构造期的 `Function<Profile,String>` | 第22节传 `MemoryService` 方法引用 |

## 4. 运行参数（读自 `Profile.settings()`）

| 键 | 默认 | 回落规则 | 消费方 |
|---|---|---|---|
| `max_iterations` | 10 | 缺失/非正数/非数字 → 10 | `ReActLoop` |
| `max_history_turns` | 20 | 缺失/非正数/非数字 → 20 | `PromptBuilder` |

## 5. 组装出的每轮请求（非持久化）

`Prompt` 的消息序列，固定顺序：

1. `SystemMessage`：`identity.agentName` + `identity.prompt` + 启动信息文件内容 + 能力包元数据行（`- <name>: <description>（读取路径: <绝对路径>）`），末尾附当前日期时间
2. 长期记忆（供给函数返回非空白时才有该条 `SystemMessage`；未启用则整段跳过）
3. 截断后的对话历史（最近 `max_history_turns` 轮）

工具说明不在 `Prompt` 内——它经 `LlmCaller.chat(..., tools, prompt)` 的 `tools` 参数交给 Provider 翻译（第16节 `ToolSchemaAdapter`），与课件骨架 `promptBuilder.build(session, profile)` 无 tools 形参一致。
