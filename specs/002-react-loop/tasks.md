## Phase 3: User Story 1 - 多轮"想—做—看"直到把事办成 (Priority: P1) 🎯 MVP

**Goal**: 自实现循环：无工具调用一轮收尾；有调用则执行并回填进下一轮；每轮响应与工具结果都累积进会话

**Independent Test**: `mvn test -pl fourfeetcat-core`，`ReActLoopTest` 绿（替身 `PromptBuilder`/`LlmCaller`/`ToolExecutor`，不碰网络）

### Tests (harness 先行)

- [x] T010 [US1] `fourfeetcat-core/src/test/java/org/fourfeetcat/core/react/ReActLoopTest.java`：纯文本响应一轮收尾（`verify(llmCaller, times(1))`）；首轮要求调工具、次轮给答复（工具被执行一次、结果进入下一轮、最终答复被返回）；一次响应多个工具调用按序执行；每轮响应与工具结果都累积进 Session（断言消息序列含用户消息、助手响应、工具结果）

### Implementation

- [x] T011 [US1] `fourfeetcat-core/src/main/java/org/fourfeetcat/core/react/ReActLoop.java`：`run(session, userMessage, profile)`——追用户消息 → `promptBuilder.build` → `llmCaller.chat(session.id(), profile, toolExecutor.descriptors(profile.tools()), prompt)` → 累积响应 → 无工具调用即返回文本 → 有则逐个 `toolExecutor.execute` 并回填 → 进下一轮（课件骨架逐行对齐；无框架 Agent 抽象，宪法原则一）

**Checkpoint**: US1 独立可测——循环走通、结果累积

## Implementation Strategy

### MVP First (User Story 1 Only)

Phase 1 → Phase 2 → US1 即得"循环走通、结果累积"的最小闭环；US2 补上限兜底、US3 补审计落库、US4 补上下文组装、US5 补编排、US6 补启动上下文。
