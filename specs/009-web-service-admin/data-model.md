# Phase 1 Data Model：Web Service 与第一版管理平台（第26节）

**本节零持久化**：不新增实体、不新增表、不新增迁移脚本、不新增落库调用。对外呈现的一切都是既有落库内容（`sessions` 表、长期记忆文件/表）与既有内存注册表（Agent 注册表、工具表、Provider 声明）的**只读投影**。下面描述的是**对外视图**（响应体形状）、**请求体**、以及限制与状态规则。

---

## 一、统一信封（成功与失败共用，既有类型，零新增）

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | int | 与 HTTP 状态码同值：成功 200；失败 400 / 404 / 500 / 503 / 504 |
| `message` | String | 可读消息；**失败时的 500 一律取既有内部错误话术**，不含任何内部细节 |
| `data` | 泛型 | 成功时的数据体；失败时为 `null` |
| `timestamp` | Instant | 生成时刻 |

> 复用第24节已建的类型（`fourfeetcat-web` 的 `api` 包），**本节不另建错误体**（课件正文口径）。仅 `ErrorCode` 枚举**新增一项**：`REQUEST_TIMEOUT(504)`（既有五项：200/400/404/500/503）。

## 二、对外视图

### 2.1 会话视图（`SessionView`，列表页与详情页共用）

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `sessionId` | String | `SessionRepository` | 会话标识（`渠道:用户:Agent` 拼出，本节不参与拼接） |
| `profileName` | String | 同上 | 归属 Agent 名 |
| `channel` | String | 同上 | 接入渠道（Web 入口固定 `web`） |
| `userId` | String | 同上 | 用户标识（一次性调用为随机唯一值） |
| `status` | String | 同上 | `active` / `archived` |
| `createdAt` | String | 同上 | ISO-8601 文本（与既有落库口径一致） |
| `lastActiveAt` | String | 同上 | ISO-8601 文本 |
| `archivedAt` | String（可空） | 同上 | 归档时刻；未归档为 `null` |

### 2.2 会话详情（`SessionDetailView`）

= 会话视图（**嵌套为 `session` 字段**，不摊平——八个字段摊平后与视图重复一遍，两处迟早改不同步）+ 下两项：

| 字段 | 类型 | 说明 |
|------|------|------|
| `messages` | `MessageView` 列表 | **最近 100 条**（按发生顺序）；超限时保留最近的 |
| `truncated` | boolean | 因超过 100 条而被截断时为 `true`——客户端据此知道历史不完整（不静默） |

`MessageView`：`role`（`user` / `assistant` / `tool` / `system`，由既有消息类型映射）+ `content`（文本）。工具结果消息取其对模型的文本呈现。

### 2.3 Agent 视图（`AgentView`）

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `name` | String | 既有 Agent 注册表 | 唯一名（注册表的索引键） |
| `description` | String（可空） | 同上 | 人类可读描述 |
| `agentName` | String（可空） | 同上 | 展示名（呈现身份） |
| `provider` / `model` | String（可空） | 同上 | 该 Agent 用哪家 provider、哪个模型 |
| `tools` | String 列表 | 同上 | 声明的工具名清单 |
| `channels` | String 列表 | 同上 | 声明的接入渠道清单 |

> **绝不出现**：凭证类字段、系统提示正文。理由：`/profiles` 是"有什么 Agent"的清单，不是配置导出。

### 2.4 工具视图（`ToolView`）

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `name` | String | 既有工具表 | 工具名（模型点名用的那个） |
| `description` | String | 同上 | 给模型看的说明 |
| `inputSchema` | String | 同上 | 参数 JSON Schema **文本**（与内部同一口径，不做二次转换） |

### 2.5 Provider 状态视图（`ProviderView`）与运行信息（`InfoView`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | String | 全局声明里的 provider 名（显式映射表的 key） |
| `baseUrl` | String | 该 provider 的端点 |
| `credentialConfigured` | boolean | **凭证是否已就位**（环境变量是否解析出非空值）——**回显凭证本身是红线，绝不出现** |

`InfoView` = 应用名 + 版本（可空）+ `providers` 列表。

> 口径说明：`credentialConfigured` 是**配置态**，不是连通态——本节不发探活请求（spec Clarifications 已裁）。运行状态页因此呈现"配了几家、哪家还没配 key"，而非"哪家此刻通"。

### 2.6 无状态调用的响应（`InvokeResponse` / `MessageResponse`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `reply` | String | Agent 的回复文本 |

> 两个响应同形（都只有一个 `reply`），实现上可共用一个记录；**不返回会话标识**——一次性调用的调用方不需要、也不该被要求维护它。

## 三、请求体

| 端点 | 请求体 | 字段规则 |
|------|--------|---------|
| `POST /sessions` | `CreateSessionRequest`（**整体可空**） | `agent`（可空 → 取注册表第一个已加载 Agent）、`user`（可空 → `anonymous`）；渠道固定 `web`，不开放给调用方 |
| `POST /sessions/{id}/messages` | `MessageRequest` | `content`：**必填**、去空白后非空、长度 ≤ 32 * 1024 |
| `POST /agents/{name}/invoke` | `MessageRequest` | 同上一行的规则 |
| 其余端点 | 无请求体 | — |

## 四、规则与状态

### 4.1 会话状态机（既有两态，本节只增加约束）

```text
（首次落盘）→ active ──归档──→ archived
                  ↑              │
                  └── 不提供复活路径 ┘
```

| 迁移 / 动作 | 规则 |
|------------|------|
| 建会话 | 走既有 `getOrCreate`（同三元组幂等）；首次落盘写 `createdAt` 与 `active` |
| 发消息 | 目标会话必须存在（否则 404）且为 `active`（否则 400，**不静默复活**）；成功后刷新最后活跃时间（既有语义） |
| 归档 | 目标会话必须存在（否则 404）；置 `archived` 并写归档时刻；**重复归档幂等**，且**不覆盖首次归档时刻** |
| 查历史 | 归档会话照常可查（归档是软标记，数据一行不删） |
| 列会话 | 返回**全部**会话（含归档），按最后活跃时间倒序；不做归档过滤——"列表 = 全部会话"保持为真 |

### 4.2 一次性调用会话的身份规则

- 每次调用构造一个**唯一**用户标识（`UUID` 去横线，32 位十六进制），与既往调用不共用。
- 会话标识仍由既有唯一位置拼接（`web:<随机值>:<Agent名>`）；**长度边界**：Agent 名超过 27 字符时标识越界 `VARCHAR(64)`（SQLite 不强制、PostgreSQL 会拒绝）——既有列宽约束，登记在 contracts 的边界说明里，本节不改表。
- 该会话与对话会话**同表同结构**，只是不会被后续调用复用；它照常出现在会话列表与审计里（如实呈现，不做隐藏）。

### 4.3 限制规则

| 限制 | 值 | 超限行为 |
|------|-----|---------|
| 单条消息长度 | 32 * 1024 字符 | 400（恰好等于上限放行） |
| 消息内容 | 非空、非纯空白 | 400 |
| 会话历史返回条数 | 最近 100 条 | 只返回最近 100 条 + `truncated=true` |
| 单次模型调用时长 | 60 秒 | 504（超时以传输层失败浮现，由统一出口按原因链识别） |

## 五、不做的事（与 spec 边界对齐）

- 不新增表/列/迁移脚本；不改 `sessions` 表结构（含不扩列宽）。
- 不新增落库调用：Web 触发那一轮的审计由既有 `ReActLoop` / `ToolExecutor` 路径写入。
- 不做认证、鉴权、限流、跨域白名单、流式响应、写操作端点。
- 不做会话删除（归档是软标记）、不做归档恢复。
